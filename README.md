# Development of a Real-time Temperature and Humidity GUI Display Using API Key

라즈베리파이와 OpenWeatherMap API를 활용하여 전 세계 실시간 기상 데이터를 수집하고, 이를 GUI(사용자 인터페이스) 환경에 시각화하는 IoT 소프트웨어 프로젝트입니다.

> 본 프로젝트는 'API Key' 인증을 통한 외부 서버와의 데이터 통신을 구현하며,
> JSON 데이터 파싱 및 실시간 이벤트 루프를 통한 자동 갱신 메커니즘을 심층적으로 다룹니다.

## 개요

라즈베리파이의 네트워크 기능을 통해 OpenWeatherMap에서 제공하는 기상 데이터를 호출하고, 파이썬의 Tkinter 라이브러리를 이용하여 온도와 습도를 화면에 표시합니다. API Key의 보안 메커니즘과 JSON 데이터 구조를 이해하고, 비정지(Non-blocking) 방식의 실시간 데이터 업데이트 기술을 학습합니다.

## 핵심 특징

- **실시간 데이터 수집**: OpenWeatherMap API를 통해 특정 지역(서울)의 기상 정보를 실시간으로 획득
- **API 보안 인증**: 고유 API Key를 활용한 서버 요청 유효성 검증 프로세스 적용
- **데이터 시각화**: Tkinter GUI를 활용하여 온도와 습도를 직관적인 UI로 제공
- **자동 갱신 로직**: after() 함수를 이용한 60초 주기 자동 업데이트 시스템 구현
- **경량 데이터 처리**: 표준 JSON 형식을 파싱하여 필요한 기상 수치만 정밀하게 추출

## 소프트웨어 아키텍처

본 프로젝트는 외부 기상 서버와 클라이언트(라즈베리파이) 간의 요청-응답 모델을 기반으로 설계되었습니다.

## 통신 및 라이브러리 이론

- **API(Application Programming Interface)**: 서로 다른 소프트웨어 간 데이터 교환을 위한 규칙 및 프로토콜 정의
- **API Key**: 사용자의 권한을 확인하고 API 호출 횟수를 관리하기 위한 고유 인증 문자열
- **urllib.request**: 네트워크를 통해 URL 경로의 데이터를 메모리로 읽어오는 역할 수행
- **JSON 파싱**: 복잡한 트리 구조의 데이터에서 data["main"]["temp"]와 같은 키 값을 통해 정보 추출

## 실행 및 설치

### 1. API Key 발급 및 설정

OpenWeatherMap 공식 사이트에 회원가입 후 발급받은 본인의 API Key를 코드 내 API_KEY 변수에 입력합니다.

### 2. 프로그램 실행

터미널에서 소스코드가 있는 디렉토리로 이동 후 'python3 main24-3.py' 명령어를 입력합니다.

### 3. 기능 설명
- 실행 시 400x100 크기의 고정된 GUI 창이 생성됩니다.
- 1분(60,000ms)마다 서버에 접속하여 최신 기상 정보를 갱신합니다.
- units=metric 옵션을 통해 화씨가 아닌 섭씨 단위를 사용합니다.

## 주요 이슈 해결
- API 요청 최적화: 무분별한 API 호출로 인한 차단을 방지하기 위해 after() 함수로 1분 간격의 갱신 주기를 설정하여 안정적인 통신 환경을 구축함.
- 데이터 포맷팅: 서버에서 전달되는 실수형 온도 데이터를 소수점 첫째 자리(.1f)까지 제한하여 GUI 상의 가독성을 확보함.
- 비정지형 루프 구현: time.sleep() 사용 시 GUI 화면이 멈추는(Freezing) 현상을 해결하기 위해, Tkinter의 이벤트 루프와 호환되는 window.after() 방식을 채택하여 실시간성을 확보함.
- API Key의 유효성이나 네트워크 연결 상태에 따라 데이터 수집이 제한될 수 있음을 파악하고, 웹 통신 기반 IoT 시스템에서의 에러 핸들링 중요성을 학습함.
